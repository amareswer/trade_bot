Summarize this session clearly and offer to save relevant items.

**Step 1 — Summarize the session**

Review the full conversation and produce this format:

```
## Session Recap

**What we did:**
- [bullet points — keep each to one line]

**Decisions made:**
- [bullet points, or "None this session"]

**Bugs fixed:**
- [bullet points, or "None this session"]

**Direction changes:**
- [bullet points, or "None this session"]

**Open items — not finished yet:**
- [bullet points, or "None"]
```

Be specific. "Fixed the auth bug" is better than "worked on some issues."

**Step 2 — Suggest what to save**

After the recap, say:

"Want me to save any of this to memory?"

List the specific items worth saving:
- Each decision that was made
- Each bug that was fixed
- Progress updates if the stage changed

**Step 3 — Save if confirmed**

If the user says yes, follow the same process as /mem-save.
Ask for confirmation before writing anything.
